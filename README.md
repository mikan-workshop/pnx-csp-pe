# csp-ex

Extended repository based on the **Common Source Code Project (CSP)** by Toshiya Takeda.

## Overview
- **`baseline` branch:** Clean mirror of official CSP release archives (CP932 / original structure).
- **`main` branch:** Development branch with UTF-8 (with BOM) encoding standardization, bug fixes, and VM core improvements.

## Related Projects
- **[pnx-csp-pe](https://github.com/mikan-workshop/pnx-csp-pe):** Portable Engine fork targeting Windows, Linux, and ESP-IDF (part of the FM Phoenix Project).

# csp-ex (日本語)

武田俊也氏による **Common Source Code Project (CSP)** をベースとした拡張リポジトリです。

## 概要
- **`baseline` ブランチ:** 本家CSPの公式リリースアーカイブをそのまま保持する基準ブランチ（CP932 / オリジナル構成）。
- **`main` ブランチ:** ソースコードの UTF-8（BOM付き）統一、バグ修正、および仮想マシン（VM）コアの改善を行う開発ブランチ。

## 関連プロジェクト
- **[pnx-csp-pe](https://github.com/mikan-workshop/pnx-csp-pe):** Windows / Linux / ESP-IDF 向けのマルチプラットフォーム移植版（FM不死鳥計画）。
